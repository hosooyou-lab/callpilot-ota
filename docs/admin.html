🚀 PC 업데이트 발행

이 PC의 콜파일럿 소스(src 폴더)를 그대로 발행하면, 전 PC가 자동으로 받아 적용합니다.
① src 폴더 선택 → 바뀐 파일 자동 확인 → ② 발행 버튼. (첫 사용 때만 아래 토큰·서명키 등록)

현재 발행 상태 확인 중…
⚙ 발행 설정 (첫 사용 때 한 번만)
만드는 법: github.com 로그인 → 우상단 프로필 → Settings → 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → [Generate new token] → Repository access에서 Only select repositories → callpilot-ota 선택 → Permissions에서 Contents: Read and write 하나만 켜기 → 생성된 토큰을 여기 붙여넣기. (이 브라우저에만 저장되고 발행할 때 GitHub에 커밋하는 데만 씁니다)
Downloads\콜파일럿_업데이트서명키(비공개-배포금지).json 파일을 메모장으로 열어 전체 복사 → 붙여넣기. 앱은 이 키로 서명된 업데이트만 믿고 적용합니다. 파일은 절대 남에게 주거나 저장소에 올리지 마세요.
